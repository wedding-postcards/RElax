# Релаксит

Публичная версия сайта конструкторско-технологического бюро «Релаксит». Мы разрабатываем и производим оборудование для коррекции формы и стабилизации геометрии подшипниковых колец.

Сайт статический: исходная страница — `index.html`. Для локального просмотра откройте папку через HTTP-сервер. Числовые характеристики станка на сайте приведены как проектные; они подлежат подтверждению испытаниями.
